# Telecom Marketing Campaign Prediction

This project builds a binary classification model to predict whether
a customer will subscribe to a telecom marketing offer.

## Objective
Predict subscription probability using supervised learning techniques.
Performance is evaluated using ROC-AUC.

## Project Structure
- notebooks/ – analysis and modeling
- data/ – training and test datasets

## Workflow
- Exploratory Data Analysis
- Data preprocessing
- Feature engineering
- Model training and evaluation
- ROC curve and AUC analysis

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib
